## 💻 Run Locally (2 minutes)

### Prerequisites:
- Node.js installed? Check: `node --version`
- No? Download from: https://nodejs.org

### Commands:

```bash
# 1. Clone (10 seconds)
git clone https://github.com/m6998499/Glass-melanin.git
cd Glass-melanin

# 2. Install (30 seconds)
npm install

# 3. Start (5 seconds)
npm run dev
```

✅ Open http://localhost:5173 - Your site is running!

---

## 🎨 Customize in 30 Seconds

### Edit Your Brand Name:

1. Open `src/App.jsx` (line 57)
2. Change `"MELANIN UNITY"` to `"YOUR BRAND"`
3. Save
4. Refresh browser - Done!

### Edit Your Headline:

1. Same file `src/App.jsx` (line 113)
2. Change `"Melanin Unity."` to your text
3. Save and see it live!

## 🆘 Having Issues?

### Build won't start?
```bash

npm install
npm run dev
```

### Port already in use?
The dev server will automatically try another port (5174, 5175, etc.)
