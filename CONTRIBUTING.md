# Contributing to Melanin Unity Crystal Glass

Thank you for your interest in contributing! This project welcomes contributions from everyone.

## 🚀 Quick Start for Contributors

1. **Fork** this repository
2. **Clone** your fork: `git clone https://github.com/YOUR_USERNAME/Glass-melanin.git`
3. **Create a branch**: `git checkout -b feature/your-feature-name`
4. **Install dependencies**: `npm install`
5. **Start dev server**: `npm run dev`
6. **Make your changes**
7. **Test your changes**: `npm run build` (ensure it builds successfully)
8. **Commit**: `git commit -m "Add: your feature description"`
9. **Push**: `git push origin feature/your-feature-name`
10. **Create a Pull Request**

## 🎯 Ways to Contribute

- **Bug fixes**: Found a bug? Submit a fix!
- **Features**: New components, animations, or functionality
- **Documentation**: Improve README, add examples, fix typos
- **Design**: Suggest UI/UX improvements
- **Performance**: Optimize rendering or bundle size
- **Accessibility**: Improve a11y features

## 📝 Commit Message Guidelines

Use clear, descriptive commit messages:

- `Add: new feature or component`
- `Fix: bug description`
- `Update: modification to existing feature`
- `Docs: documentation changes`
- `Style: formatting, whitespace, etc.`
- `Refactor: code restructuring`
- `Test: adding or updating tests`

Examples:
```
Add: responsive mobile navigation menu
Fix: animation glitch on hero section
Update: improve contrast for accessibility
Docs: add deployment instructions for AWS
```

## 🔧 Development Guidelines

### Code Style

- Use **functional components** with hooks
- Follow existing **Tailwind CSS** patterns
- Use **Framer Motion** for animations
- Keep components **small and focused**
- Add **comments** for complex logic

### Testing Changes

Before submitting a PR:

```bash
# 1. Build succeeds
npm run build

# 2. No console errors
npm run dev
# Check browser console

# 3. Responsive design works
# Test on mobile, tablet, desktop viewports

# 4. Lint passes (if applicable)
npm run lint
```

### File Organization

```
Glass-melanin/
├── src/
│   ├── App.jsx                # Main component
│   ├── main.jsx               # Entry point
│   └── index.css              # Global styles
├── public/                    # Static assets
└── [config files]             # Vite, Tailwind, etc.
```

## 🎨 Design Principles

This project follows these design principles:

1. **Crystal Glass Aesthetic**: Glassmorphism with subtle blur and transparency
2. **Pan-African Colors**: Red, yellow, green accents throughout
3. **Smooth Animations**: Subtle motion that enhances UX
4. **Modern & Clean**: Minimalist design with clear hierarchy
5. **Accessible**: WCAG compliant where possible

## 🐛 Reporting Bugs

When reporting bugs, please include:

1. **Description**: Clear description of the issue
2. **Steps to reproduce**: How to trigger the bug
3. **Expected behavior**: What should happen
4. **Actual behavior**: What actually happens
5. **Screenshots**: If applicable
6. **Environment**: Browser, OS, Node version

## 💡 Suggesting Features

For feature requests, please:

1. **Check existing issues** to avoid duplicates
2. **Describe the feature** clearly
3. **Explain the use case**: Why is it needed?
4. **Provide examples**: Mockups, code samples, etc.
5. **Consider alternatives**: Other ways to achieve the goal

## ✅ Pull Request Checklist

Before submitting your PR:

- [ ] Code builds successfully (`npm run build`)
- [ ] Changes are tested in browser
- [ ] Responsive design verified (mobile, tablet, desktop)
- [ ] No console errors or warnings
- [ ] Code follows existing style patterns
- [ ] Commit messages are clear and descriptive
- [ ] PR description explains changes
